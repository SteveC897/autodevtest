# 2026-10-17 · sp-20261017-001 交付记录

## 做了什么

从空目录搭出 Vampire Survivors 超小原型，并把"可验证"作为结构约束：

- `world.py` 纯逻辑（不依赖 pygame），`render.py` 纯绘制，`app.py` 输入与主循环
- `config.py` 收敛全部手感参数
- 11 个逻辑单测 + `scripts/verify.py`（19 项无头检查，含 3 张截图与 JSON 报告）
- 仓库宪法 `AGENTS.md`、验证技能 `.dsh/skills/verify-game/SKILL.md`

## 关键决定

1. **接触伤害加 0.6s 冷却。** 不加的话，三个敌人贴脸会在 0.1 秒内秒杀，原型无法试玩。这是对原描述的一处偏离，已写进 spec 的 ac6 与 AGENTS.md §6。
2. **敌人在 520px 外生成。** 视野对角线约 566px，520 保证"从视野外走进来"，同时不会一生成就在射程内。
3. **敌人 30 血 / 子弹 15 伤。** 两发一只。击杀速率（约 0.9s/只）慢于刷怪（0.55s/只），所以站着不动必死——这是"有压力"的最小实现，也顺带让失败分支可自动验证（20.9 秒死亡）。
4. **胜负同帧判负优先。**
5. **验证脚本读像素而不是只读状态。** 纯逻辑测试证明不了"画面对不对"，这正是验证技能存在的理由。
